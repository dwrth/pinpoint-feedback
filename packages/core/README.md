# @pinpoint-feedback/core

Framework-independent screenshot capture, annotation editor, browser client and i18n.

Part of [Pinpoint Feedback](https://github.com/dwrth/pinpoint-feedback): visual website feedback that lands in Notion. Most apps install the umbrella package instead:

```bash
npm install pinpoint-feedback
```

Docs: https://github.com/dwrth/pinpoint-feedback#docs
